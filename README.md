# kak_ze_zaebalo_date_time

Инлайн-бот для Telegram: набираете `@имя_бота` в любом чате и получаете гифку с Шелби
и подписью «Как же заебало 18 ноября» — с текущей датой или с датой и временем.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и включите ему инлайн-режим командой `/setinline`.
2. Напишите боту `/start` в личку. Туда он будет на секунду присылать гифки: Telegram
   отдаёт `file_id` для инлайн-ответа только после отправки файла в какой-нибудь чат.
3. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `STORAGE_CHAT_ID` — ваш user id (подскажет, например, [@userinfobot](https://t.me/userinfobot));
   - `TZ` — часовой пояс для тех, кто не настроил свой, по умолчанию `Europe/Moscow`;
   - `TELEGRAM_PROXY` — прокси до `api.telegram.org` (`socks5://user:password@host:1080`),
     если сервер не достаёт до Telegram напрямую. Без него бот перезапускается по кругу
     с ошибкой `Request timeout error`.
4. Запустите: `docker compose up -d --build`

Логи: `docker compose logs -f`

## Часовой пояс

Каждый пользователь может задать свой: над результатами инлайн-запроса есть кнопка
«Часовой пояс … — изменить», она открывает личку с ботом. Туда нужно прислать смещение
от UTC (`+3`, `-5`) или название пояса (`Europe/Belgrade`). Название надёжнее: оно
учитывает переход на летнее время.

Настройки хранятся в SQLite в docker-томе `data` и переживают пересборку контейнера.
